# Repository contents

Source pages and language content are under `client/src`; public derivatives and the two credited photographs are under `client/public/assets`. Four large working art/logo originals are preserved under `assets/originals` and excluded from the deployed asset directory. Runtime configuration and lockfile are at the root; static prerendering is in `scripts/prerender.tsx` and the ASSETS Worker is `server/worker.ts`.

See `README.md` for commands, `PUBLIC_SOURCES.md` for visitor evidence and `ASSET_SOURCES.md` for provenance. A local build or archive is not a verified production release. The earlier snapshot checksum list was removed because it no longer described the current tree.
